# The lexicon layer

Above the letter stages (data/stages) sits the lexicon: word-level knowledge
a spelling needs where letters alone cannot decide. One format for every
language, in two files per code:

- `<code>.yaml`, written by hand: the name, the kind, the sources, and the
  small hand tables (Latin phrases, a host's spoken words).
- `<code>.json`, generated by scripts/gen_lexicon.py from the sources under
  `sources/` (downloaded, gitignored, licences beside them): the big tables.

A lexicon has:

- `read`: spelling → script text, per word (English: the pronunciation
  dictionary; Mandarin: the pinyin syllables). Consulted before the letters.
- `write`: script text → spelling, per word or, with `match: prefix`, per stem
  (Hungarian: the ly stems, so folyó writes ly where the letters would write
  j). Consulted before the letters when rendering.
- `choices`: script text + tone sign → the characters to choose from (Mandarin:
  from Unihan, ordered by frequency).
- `loans: true`: the host catches loans, through the one loan dictionary
  every host shares (below). A loan keeps the sounds of the language it
  comes from: meeting in a Hungarian text is mítiṇ, as English says it.
  With a `native` list (the host's dictionary) the longest matching stem
  decides between native and loan, native on ties unless the stem has a
  `foreign` letter shape; a suffixed word whose stem has no foreign shape
  is never a loan (akinek is aki + nek, whatever English has in akin),
  with the shape the rest is read by the host's letters
  (streaming + ajánlójában); `lengthen` names the final vowels a suffix
  lengthens (Hungarian á → a, é → e), so the stem of traumái is trauma.
  `spoken` (Hungarian) lists the host's own words in an old spelling it
  reads its own way (pech: peh) and `names` a person's own entries; both
  matched as stems. `borrowed` names loans the host's dictionary lists as
  its own and no shape betrays (online, summa): they read in their own
  language.

## The loan dictionary

A word is written as its language of origin says it, the same in every
text: one Diafon form, whatever a host spells it. So the loans live in one
dictionary, `loans.json`, generated by scripts/gen_lexicon.py and consulted
by every host with `loans: true`; a host keeps only what tells its own
words from loans (`native`, `foreign`, `lengthen`, `borrowed`) and how it
writes a loan back.

- `hand`: `origin.yaml`, the words no dictionary here reads, or reads
  otherwise than the hosts borrow them, as their own language says them, in
  the script (jamaica: x̦ạmejkạ, bach: baḳ). Matched as stems
  (jamaicai, Jamaicában), ahead of a host's dictionary.
- `read`: the dictionaries, per origin: Latin (la.yaml), English (CMUdict,
  its common words only: the frequency list, not the names). A spelling
  is in one of them only: hand first, then Latin, then English.
- `write`: script text → the original spelling.
- `hosts`: per host, its own spellings of a loan, from origin.yaml.
  `also` spellings read as the loan and write back in the original
  (Hungarian míting is mítiṇ, written meeting); `spell` is how the host
  writes the loan back, and it reads too (Hungarian lájk: like and lájk are
  both lajk, written lájk; Czech Jamajka). Diafon has one form for the word;
  the host spellings it comes from and goes back to may differ.

A language may have a stage and no lexicon (Czech), a lexicon and no stage
(English, whose spelling is lexical through and through; Mandarin, whose
spelling is the syllable), or both (Hungarian). The reader's order for a
word of a host with letters: the loan check (the longest stem a loan
lexicon reads, against the host's dictionary and its own entries, above),
else the host's own entries (`spoken`, a stem and the rest by the
letters), else the letters when they read it in full, else the letters
with aliases and the script as fallback. For a lexical stage (English,
Mandarin): the lexicon, else the fallback. The writer's order: the lexicon
(word, then stem), else the letters.
