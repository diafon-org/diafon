# The lexicon layer

Above the letter stages (data/stages) sits the lexicon: word-level knowledge
a spelling needs where letters alone cannot decide. One format for every
language, in two files per code:

- `<code>.yaml`, written by hand: the name, the kind, the sources, and the
  small hand tables (Latin phrases, the folding of loans into a host).
- `<code>.json`, generated by scripts/gen_lexicon.py from the sources under
  `sources/` (downloaded, gitignored, licences beside them): the big tables.

A lexicon has:

- `read`: spelling → transport, per word (English: the pronunciation
  dictionary; Mandarin: the pinyin syllables). Consulted before the letters.
- `write`: transport → spelling, per word or, with `match: prefix`, per stem
  (Hungarian: the ly stems, so folyó writes ly where the letters would write
  j). Consulted before the letters when rendering.
- `choices`: transport + tone → the characters to choose from (Mandarin:
  from Unihan, ordered by frequency).
- `loans`: the lexicons a host consults for a word its own letters cannot
  read (Hungarian: en, la), and `fold`: how the loan's sounds land in the
  host's own (θ → t, w → v, æ → e…), a segment-sequence rewrite. With a
  `native` list (the host's dictionary) the longest matching stem decides
  between native and loan, native on ties unless the stem has a `foreign`
  letter shape; a loan stem is one of the source's `common` words (English:
  the frequency list, not CMUdict's names); a suffixed word whose stem has
  no foreign shape is never a loan (akinek is aki + nek, whatever English
  has in akin), with the shape the rest is read by the host's letters
  (streaming + ajánlójában); `lengthen` names
  the final vowels a suffix lengthens (Hungarian á → a, é → e), so the
  stem of traumái is trauma. `spoken` (Hungarian) lists spellings the host
  keeps and reads its own way, neither by the letters nor as a loan
  (jamaica: jamaika, bach: bah), and `names` the proper names no
  dictionary reads (cudjoe: kadzsó), the same table kept apart for review;
  matched as stems.

A language may have a stage and no lexicon (Czech), a lexicon and no stage
(English, whose spelling is lexical through and through; Mandarin, whose
spelling is the syllable), or both (Hungarian). The reader's order for a
word of a host with letters: the loan check (the longest stem a loan
lexicon reads, against the host's dictionary and its own entries, above),
else the host's own entries (`spoken`, a stem and the rest by the
letters), else the letters when they read it in full, else the letters
with aliases and the script as fallback. For a lexical stage (English,
Mandarin): the lexicon, else the fallback. The writer's order: the lexicon
(word, then stem), else the letters.
