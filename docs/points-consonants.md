# The consonant points — explained

49 consonant points across 16 languages, in plain language. Companion to the interactive
grid at [`docs/viz/consonants.html`](viz/consonants.html). For the notation proposal see
[`vowel-notation.md`](vowel-notation.md) (vowels) and the Phase-2 label sketch.

## How to read a consonant point

A **point** is the bare skeleton of a consonant — three facts and nothing else:

- **Place** — *where* in the mouth the air is blocked, front to back: lips → teeth → the ridge
  behind the teeth → the hard palate → the soft palate (velum) → the uvula → the throat.
- **Manner** — *how* the air is blocked: a full **stop**, a stop released into a hiss
  (**affricate**), a continuous hiss (**fricative**), air rerouted through the nose (**nasal**),
  a vibrating or flicked tongue (**trill / tap**), or a barely-there vowel-like **approximant**.
- **Voice** — are the vocal cords buzzing (**voiced**, like `b`) or silent (**voiceless**, like `p`).

Two sounds from different languages are the **same point** when all three match. Everything
else — a puff of air, a "y" colour, lip-rounding, length — is a *modifier* that rides on top
without creating a new point (see the end of this file).

> Example words are anchors for the ear, not exact equivalences: the same point sounds a little
> different from language to language.

## Resolved: two allophones removed

Two fricative "points" turned out to rest entirely on **allophones** — not separate phonemes
in the only language that had them — and were removed (49, down from 51):

- **`ç` (was DE)** — German *ich-laut*. [ç] and [x] (*ach-laut*) are one phoneme in
  complementary distribution ([ç] after front vowels, [x] after back). Folded into `x`. This
  is exactly the *ich* ≈ *loch* closeness — the same German phoneme.
- **`ɸ` (was JA)** — [ɸ] is the allophone of /h/ before /u/ (ふ *fu*). Folded into `h`. The
  point may return later as a genuine contrast if **Ewe** (which contrasts /f/ vs /ɸ/) is added.

The near-merge finder missed both because it only flags pairs that **don't** co-occur — and
allophones co-occur. `derive()` now also emits a **suspicious co-occurrence** list (rare points
sitting one step from a same-language neighbour) that catches this class. It flagged `ç`~`x`,
`ɸ`~`h`, and `a`~`ɐ` — all now resolved (`ɐ` removed too; see
[points-vowels.md](points-vowels.md)). The list is empty and a test keeps it so.

## The modifiers (ride on any point, never make a new one)

| Mark | Feature | Plain meaning | Example |
|---|---|---|---|
| `ː` | long | Hold it longer | Italian *nonno* |
| `ʰ` | aspirated | A puff of air after (always voiceless) | English *pin*; Korean/Mandarin contrast it |
| `ʲ` | palatalised | Add a "y" colour | Russian soft *нь* |
| `ʷ` | labialised | Add lip-rounding | a "w" colour |
| `ˤ` | pharyngealised | Pull the tongue root back — "darker" | Arabic emphatic *ṭ ṣ* |
| `˞` | rhotic | Add "r" colour (mainly vowels) | American *bird* |
