Fonts

Every glyph the system can draw, as one matrix: bases across, derivations down, in the three Diafon families or any other face.

The text is the marks. Every glyph is a base letter plus the system's own combining marks, normalised: where Unicode has a letter for the pair (ș ṭ ä á) it appears as that letter, elsewhere the sequence stands (t̤ k̦ ȁ), and both are the same text to Unicode. The Diafon fonts draw the marks as designed; any other face draws them its own way, which is what a reader without the font sees. The fonts are served by the site: web font services that cut a family into fixed subsets drop five of the marks.

Where this goes. Latin Extended is a thicket: every language grew its own marks for the same sounds, cedilla here, caron there, ogonek, dot, hook. Diafon writes all of them with one small set of marks on one small set of letters, so the same sound looks the same in every language. The web letters are the bridge through today's repertoire; in the longer run the aim is to let that mess fall away and keep only the unified glyphs. Faded tiles are the grammar's reserve, drawn by the rules but used by no current language. Part of Diafon.
