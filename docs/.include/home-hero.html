Diafon

One alphabet for the sounds of many languages.

One sound, /t͡ʃ/, spelled five ways. Diafon writes it c̦ in each of them.

Czechčokoláda→c̦okoláda
Turkishçikolata→c̦ikolata
Hungariancsokoládé→c̦okoládé
Swahilichokoleti→c̦okoleti
Englishchocolate→c̦óklạt

One alphabet for many languages

A phonemic Latin alphabet. Each letter stands for one sound and is read much the same way across languages, so a new word can be read close to how it is said.

The 26 Latin letters as easy input

Everything is typed with the plain Latin letters, without dead keys. There are a few letter combinations to learn.

Your language's own spelling too

Text can be converted to and from the usual spelling of the supported languages, Pinyin included.

One keyboard layout for fast typing

The supported languages can all be typed on one layout, without switching between keyboards.
