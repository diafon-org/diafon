Diafon

One alphabet for the sounds of many languages.

One sound, /t͡ʃ/, has four spellings here. Diafon always writes it c̦.

Czechčokoláda→c̦okoláda
Turkishçikolata→c̦ikolata
Polishczekolada→c̦ekolada
Swahilichokoleti→c̦okoleti
Englishchocolate→c̦óklët

One sound, one letter

A sound has the same letter in every language that has it.

To and from usual spelling

A text converts between Diafon and the usual spelling of each supported language, Pinyin included.

Ordinary text

Diafon is plain Unicode, Latin letters with standard marks. Any app, file or message can carry it.
