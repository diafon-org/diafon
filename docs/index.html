diaphone

One writing for every language

A phonemic writing system built from three questions, in order: which sounds must a shared writing keep apart — the points, derived so that no language's minimal pair is ever merged, and proven so; how do you type them — the codes, plain ASCII letters, proven to decode one way only; how should they look — the views, one universal (our Latin-plus-marks glyphs, or IPA for reference) plus, per language, its own familiar spelling. The first is a claim, the second a guarantee, the third a choice — which is why only the third has options. Below: the points, then the codes, then a live tryout of every view.

Section 2 · The universal input

The six operators c j q x w y — one mechanism, base-dependent

A label is a base letter plus attaching operators. Every operator is base-dependent — the same letter does one thing on a consonant, another on a vowel (x = dental on t, velar on k; y = aspirated on t, nasal on a). Four of them (c j q x) can form new points; the rule that decides each case: base+letter is that point if it exists, otherwise the letter rides on top as a modifier (sj → ș is a point, pj → p̓ a modifier; tx → ṭ a point, ux → w a modifier).
