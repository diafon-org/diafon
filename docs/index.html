Part 1 · The phonemic system

The seven operators c j q x w h y — one mechanism, base-dependent

A label is a base letter plus attaching operators. Every operator is base-dependent — the same letter does one thing on a consonant, another on a vowel (x = dental on t, velar on k; y = emphatic on t, nasal on a). Four of them (c j q x) can form new points; the rule that decides each case: base+letter is that point if it exists, otherwise the letter rides on top as a modifier (sj → s̩ is a point, pj → p͈ a modifier; tc → c a point, kc → k̈ a modifier).

Part 2 · The input method

One stream, three languages the unified mode

The daily input method is one mode: English, traditional Hungarian and Pinyin in a single stream. Everything passes through exactly as typed, except two kinds of sequence:

you typeyou getrule
aw ew iw ow uwá é í ó úvowel + w = the long accent
ec ic · ecw icwö ü · ő űe/i + c = the round pair; + w = long
zhong1 · xi3huan1 · ma5zhōng · xǐhuān · maa chunk closed by a tone digit is real Pinyin (p/t/k literal; 5 = neutral)

Hungarian consonants are typed traditionally — sz, ny, gy stay themselves — so Egy kis kutya alszik az asztal alatt goes through verbatim; only accents need combos (vilawg → világ). Where an English word collides with a combo, double the operator to escape: neww → new · musicc → music · quicck → quick · item22 → item2. The full phonemic notation lives in the dedicated per-language modes below.

Simplified input loose mode, per language

Loose input adds typing shortcuts on top of the notation — the canonical codes always keep working. HU: bare a = the Hungarian short a, e = the short e. ZH: type Pinyin directly (xiao, shi, zhong).
