Every cross-linguistic point in three views at once — its IPA value, the ASCII input combo you type, and the native Latin+diacritics glyph (set in Charis SIL). Consonants on the articulatory grid, vowels on the triangle, then a tryout that converts your input into any target.

The seven operators c j q x w h y — one mechanism, base-dependent

A label is a base letter plus attaching operators. Every operator is base-dependent — the same letter does one thing on a consonant, another on a vowel (x = dental on t, velar on k; y = emphatic on t, nasal on a). Four of them (c j q x) can form new points; the rule that decides each case: base+letter is that point if it exists, otherwise the letter rides on top as a modifier (sj=ʃ a point, pj=pʲ a modifier; tc=t͡s a point, kc=kʷ a modifier).
