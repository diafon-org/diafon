The whole system

Every cross-linguistic point in three views at once — its IPA value, the ASCII input combo you type, and the native Latin+diacritics glyph (set in Charis SIL). Consonants on the articulatory grid, vowels on the triangle, then a tryout that converts your input into any target.

Operators base + one → a related point

A label is a base letter, then at most one operator (which makes a *different* point), then any modifiers (which ride on top). The four operators are base-dependent — the same letter does one thing on a consonant, another on a vowel, like x = dental on t, velar on k.

opon a consonanton a vowel

The same letter can also be a modifier on a base where that point doesn't exist: sj=ʃ (a point) but pj=pʲ (p + palatalised); tc=t͡s (a point) but kc=kʷ (k + labialised). Rule: base+op is that point if it exists, otherwise the letter rides as a modifier.
