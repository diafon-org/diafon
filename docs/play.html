Diafon playground

Type the input form, or paste a text in a language's spelling, and read the script form, live. The system is defined in the description.

wordread bytransportuniversalwritten back

Each chip: glyph · input · the selected language's reading of that form (universal shows the most common reading). Faded = the language does not use the form; red = not a well-formed segment (an operator or digit cannot start one, and a form carries at most two operators plus w). Tones are trailing digits.

With a spelling as the source, the text is read back word by word: by the letters, by the language's own lexicon, by a loan lexicon folded into its sounds (loan:en), or by the letters with the script as fallback. The second line is the same text written back in the language's spelling, a loan going out as it came in (like stays like; from a Universal text alone it could not, sjow being só as much as show); the table marks in red every word the round trip changed: a loss the spelling states, or a reading to fix. For Mandarin the chips carry the characters of each toned syllable, most frequent first. The lexicons load from docs/lexicon/, so serve this directory over http.
